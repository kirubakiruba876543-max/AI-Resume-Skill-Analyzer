# AI Resume Skill Analyzer

A simple AI/ML hackathon project that compares a resume with a job description.

## Features
- TF-IDF based text representation
- Cosine similarity match score
- Skill extraction from both texts
- Matched skills and suggested skill gaps
- Simple Streamlit web interface

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

Open the local URL shown by Streamlit.

## Tech Stack
- Python
- Streamlit
- Scikit-learn
- TF-IDF
- Cosine Similarity
